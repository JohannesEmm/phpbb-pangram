How it works: When a user with 0 approved posts submits their first post and it goes into the moderation queue, this extension calls the Pangram API to check for AI-generated content.

  • AI score ≤ {PANGRAM_APPROVE_THRESHOLD}% → post and user are automatically approved
  • AI score ≥ {PANGRAM_BAN_THRESHOLD}% → user is permanently banned (by user_id and email), post stays in queue
  • Between the two thresholds → post stays in queue for manual review

The API call adds up to ~15 seconds to the post submission for the poster. On timeout or API error the post is left in the queue silently.
